🍉 切水果 · Emoji 双刀版

一款纯前端触屏切水果游戏，运行在手机或平板的浏览器中。
🎮 三种模式 | 🔥 连击系统 | 🛒 道具升级 | 🎵 场景音乐 | 🔪 双刀跟随手指

---

✨ 游戏特色

· 触屏切割：手指在屏幕上滑动即可切水果，支持双手双刀，刀光跟随指尖
· 三种模式：
  · 🏆 经典模式（60秒）—— 炸弹较多，考验反应
  · ⚡ 街机模式（45秒）—— 节奏更快，紧张刺激
  · 🌸 休闲模式（90秒）—— 节奏舒缓，炸弹稀少
· 特殊元素：
  · 💣 炸弹：切到扣分，打断连击
  · 💎 双倍水果：10秒内得分翻倍
  · ⭐ 星星水果：额外奖励 10 分
  · 🐢 减速道具：水果下落变慢
  · 🌀 旋风道具：清除屏幕所有水果
· 连击系统：1.5 秒内连续切割累积连击，连击越高奖励越多
· 金币 & 商店：
  · 每局结束后根据得分获得金币（永久保存）
  · 可升级「锋利度」（扩大切割判定）和「金币加成」
· 场景音乐：三个场景（菜单、游玩、结算）独立背景音乐，首次触摸后播放
· 数据持久化：金币和升级等级保存在浏览器 localStorage，关掉页面也不会丢失

---

🎮 玩法说明

1. 选择模式：在开始菜单点击「经典」「街机」「休闲」切换
2. 开始游戏：点击「🔪 开始切」进入游戏
3. 切水果：单指或双指在屏幕上滑动，刀跟随手指移动
4. 躲避炸弹：切到炸弹会扣分并重置连击
5. 收集道具：切割特殊水果获得限时增益
6. 结算升级：一局结束后用金币去商店升级能力

🚀 快速开始

本地运行（Termux / 手机）

```bash
# 1. 克隆仓库或下载文件到手机
cd /sdcard/Download/Download

# 2. 安装 Python（如已安装跳过）
pkg install python

# 3. 启动本地服务器
python -m http.server 8080

# 4. 手机浏览器打开
http://localhost:8080
```

部署到 GitHub Pages

1. 将仓库上传到 GitHub
2. 在仓库设置中启用 GitHub Pages，选择 main 分支（或 docs/ 目录）
3. 访问 https://你的用户名.github.io/仓库名/ 即可游戏

📁 文件结构

```
├── 切水果.html          # 游戏主文件（所有代码）
├── 开始菜单.mp3         # 菜单背景音乐
├── 游玩时背景音乐.mp3   # 游戏背景音乐
├── 结算页面.mp3         # 结算界面音乐
└── README.md           # 本文件
```

· 所有游戏逻辑、界面、样式均在单个 HTML 文件中，无外部依赖
· 音乐文件需与 HTML 放在同一目录，文件名必须一致

---

🛠️ 技术栈

· 原生 HTML5 / CSS3 / JavaScript
· Canvas 2D 绘图
· 多点触摸事件（touchstart, touchmove, touchend）
· localStorage 数据持久化
· Web Audio（音乐播放）

---

📝 自定义

· 修改音乐：替换同名的 mp3 文件即可
· 调整难度：在代码中搜索 modeSettings，修改时间、生成间隔、炸弹概率等
· 增加水果：编辑 fruitTypes 数组，添加新 emoji 和分值
