# 🍉 切水果 · Emoji 双刀增强版

> 一款纯前端触屏切水果游戏，手机平板浏览器即开即玩。  
> 🎮 三种模式 | 🔥 连击&组合技 | ❄️ 冰冻磁铁 | 🧲 每日签到 | 🔪 清晰双刀 | 🎵 场景音乐

## ✨ 游戏特色

- **双手双刀**：两个手指滑动，刀跟随指尖，实体化清晰可见，刀大小可升级
- **三种模式**：🏆 经典（60秒）| ⚡ 街机（45秒）| 🌸 休闲（90秒），炸弹密度和速度均经过优化
- **丰富道具**：
  - 💣 炸弹：切到扣分 + 打断连击
  - 💎 双倍：10秒内所有得分×2
  - ⭐ 星星：额外 +10 分
  - 🐢 减速：水果下落变慢 8 秒
  - ❄️ 冰冻：冻结屏幕水果 5 秒
  - 🧲 磁铁：水果向你手指聚拢 6 秒
  - 🌀 旋风：瞬间清除所有非炸弹水果
- **同种水果三连组合技**：连续切三个相同水果触发全屏清场 + 额外 20 分
- **连击系统**：1.5 秒内连续切割累积连击，高分利器
- **每日签到**：每天点击菜单按钮领 100 金币
- **商店升级**：锋利度（扩大判定）、刀尺寸（更大更清晰）、金币加成（倍率提升），金币永久保存
- **场景音乐**：菜单、游玩、结算三首独立背景音乐，首次触摸后播放
- **数据持久化**：金币、等级、签到日期全部保存在浏览器 localStorage

## 🎮 玩法

1. 菜单选择模式 → 点「开始切」
2. 单指或双指在屏幕滑动，切水果、躲炸弹、收集道具
3. 注意连击和同种水果组合技
4. 时间结束后用金币去商店升级能力
5. 每天别忘了签到领金币！
